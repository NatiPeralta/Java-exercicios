# ⚡ Exercícios de Lógica e Algoritmos em JavaScript

Este repositório reúne uma série de exercícios práticos desenvolvidos em **JavaScript**, focados no fortalecimento da lógica de programação, algoritmos básicos, estruturas de controle e manipulação de arrays e objetos.

O conteúdo foi desenvolvido durante o treinamento de **Desenvolvimento Full Stack Junior** oferecido pela **+praTi**.

---

## 🎯 Conteúdos Abordados

- 🧠 **Lógica de Programação & Algoritmos:** Resolução de problemas com raciocínio lógico estruturado.
- 🔄 **Estruturas de Condição e Repetição:** Prática com `if/else`, `switch`, `for`, `while`, `do...while`.
- 📊 **Arrays e Coleções:** Iteração, filtragem, mapeamento e manipulação de vetores e matrizes.
- 📦 **Funções e Escopo:** Criação de funções reutilizáveis, modularização de código e sintaxe moderna (ES6+).
- 🧩 **Manipulação de Objetos:** Organização e acesso a estruturas de dados chave-valor.

---

## 🛠️ Tecnologias Utilizadas

- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Linguagem principal utilizada na resolução dos algoritmos.
- **[Node.js](https://nodejs.org/):** Ambiente de execução JavaScript no terminal.
- **[Git & GitHub](https://github.com/):** Controle de versão e documentação das soluções.

---
